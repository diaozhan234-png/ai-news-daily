Nvidia finds that simple linear math can replace costly AI model handoffs
When an agentic AI system hands a task from a small model to a larger one — or back down again — it pays a steep tax: the receiving model has to recompute the entire conversation from scratch, driving up compute costs and latency. This is a major bottleneck for enterprises building long-horizon, multi-LLM workflows. To solve this challenge, researchers at Nvidia have introduced a cross-model KV cache transfer technique that directly maps the prefilled KV cache from a source model into the target model. This technique aligns with real-world agentic applications where large contexts accumulate across many turns. For real-world AI applications, cross-model KV cache transfer can reduce compute costs and latency on long-running, multi-LLM workflows — and it does so with simple linear math, not an expensive deep learning model. Experiments show that, on compatible model pairs, this linear mapping process runs 2.7 to 25 times faster than recomputing the conversation while retaining up to 98% of the target model's standalone accuracy. Examining how LLMs handle memory helps understand why multi-model workflows hit a performance wall in production. When an LLM receives a prompt, it must first execute the “prefill” stage, which is the initial forward pass that computes the keys and values for all input tokens and populates the Key-Value (KV) cache. After that, it enters the “decode” phase, where it computes and generates the next tokens in the sequence. During this phase, the model reads from this KV cache to predict new tokens one by one, bypassing the need to re-evaluate the entire history of the conversation for each new token. In multi-turn conversations or long-horizon agentic sessions, the context gradually becomes longer. Because the computational cost of the prefill stage scales directly with both model size and input length, processing these long sessions becomes increasingly expensive and introduces significant latency if the KV cache is invalidated. This invalidation happens whenever the AI system tries to swap models mid-session, such as routing a complex reasoning step to a larger model or dropping to a smaller model to save costs. Because different LLMs have different architectures, they expect their cache inputs in different formats. As a result, any model switch forces the receiving model to repay the entire prefill cost from scratch to recompute the KV cache for the accumulated context. The Nvidia researchers studied cross-model KV cache transfer to see how developers can transform the KV cache of one model into the expected format of another without running the prefill phase again. If solved, cross-model KV cache transfer has benefits in both directions. Small-to-large model transfer upgrades the quality of the output. For example, a cheap, small model handles the routine parts of an agentic workflow but struggles with a complex reasoning problem, and you map the KV cache to a larger model and continue the process seamlessly. On the other hand, large-to-small model transfer reduces compute costs. A highly capable, large model might be used to unpack a massive, complex system prompt or synthesize a dense PDF at the start of a session. Once the heavy lifting is done, the session's KV cache is mapped down to a smaller, more economical model to handle the rapid-fire, conversational turns that follow. There have been previous efforts to solve the KV cache transfer problem, but they suffer from a few key limitations. These include the need for expensive gradient-based training or very strict architectural constraints. For this initial study, the authors restricted their focus to within-family transfers, such as transitioning between different-sized models in the Qwen, Llama, or Ministral families. These models share tokenizers, training data DNA, and core architectural styles but differ in size and depth. However, this framework leaves plenty of room for future experiments. The researchers note the technique could eventually be expanded to cross-family transfers, mismatched KV head counts, or hybrid architectures that blend standard attention with other memory mechanisms. The key finding of the Nvidia study is that cross-model KV cache is a significantly linear structure. This means you can do the mapping with simple algebra tricks and without the need for heavy neural network training. For example, when experimenting on KV cache transfer from a 14-billion parameter Qwen3 model to a 32-billion parameter version, the authors discovered that a simple linear regression mapping from one source layer to a target layer can recover 56% of the variance in the target’s keys and 32% of the variance in its values. When combining multiple source layers, those numbers climbed to 79% and 65% respectively. To translate this linear relationship into a practical system, the researchers designed a closed-form per-head ridge mapper with three key components: Per-head ridge regression: Instead of using complex deep learning to train the system, they fit a simple linear regression using a tiny calibration set of a few hundred text sequences. This technique solves a classic line-of-best-fit problem independently for every attention head. Cross-layer source selection: Because the source and target models have different numbers of layers, the mapper evaluates and selects the most predictive source layers to feed into each specific target layer. This way, the system picks only the most helpful pieces of memory from the old model to construct the new model's memory. Content-space mapping: Before translating the data, the mapper strips away the RoPE encodings. RoPE, or Rotary Position Embedding, is a standard mechanism that applies a mathematical, position-dependent rotation to the data so the model understands the order of the tokens in a sequence. Stripping the RoPE values makes it possible for the mapper to generalize to sequences of lengths larger than its training data.

Nvidia发现简单的线性数学可以取代昂贵的AI模型切换
当一个代理人工智能系统将一个任务从一个小模型交给一个大模型——或者再次退回——它会付出高昂的代价：接收模型必须从头开始重新计算整个对话，从而增加计算成本和延迟。这是企业构建长期、多LLM工作流的主要瓶颈。为了解决这一挑战，Nvidia的研究人员引入了一种跨模型KV缓存传输技术，该技术将预填充的KV缓存从源模型直接映射到目标模型。这种技术与现实世界中的代理应用程序相一致，在这些应用程序中，大型上下文会在许多回合中积累。对于现实世界的人工智能应用程序，跨模型KV缓存传输可以降低长时间运行的多LLM工作流的计算成本和延迟，并且它是通过简单的线性数学实现的，而不是昂贵的深度学习模型。实验表明，在兼容的模型对上，这种线性映射过程比重新计算对话快2.7到25倍，同时保留了目标模型高达98%的独立准确性。研究LLM如何处理内存有助于理解为什么多模型工作流在生产中遇到性能瓶颈。当LLM收到提示时，它必须首先执行“预填充”阶段，这是计算所有输入令牌的键和值并填充键值（KV）缓存的初始前向传递。之后，它进入“解码”阶段，在那里它计算并生成序列中的下一个令牌。在此阶段，模型从该KV缓存中读取数据，逐一预测新令牌，无需重新评估每个新令牌的整个对话历史。在多回合对话或长时间代理会话中，上下文逐渐变长。由于预填充阶段的计算成本与模型大小和输入长度直接成比例，因此处理这些长会话变得越来越昂贵，如果KV缓存无效，还会引入显著的延迟。每当人工智能系统试图在会话中期交换模型时，就会发生这种失效，例如将复杂的推理步骤路由到更大的模型，或者放弃到更小的模型以节省成本。因为不同的LLM具有不同的架构，所以它们期望缓存输入采用不同的格式。因此，任何模型切换都会迫使接收模型从头开始偿还全部预填充成本，以重新计算累积上下文的KV缓存。英伟达的研究人员研究了跨模型的KV缓存传输，以了解开发人员如何在不再次运行预填充阶段的情况下将一个模型的KV高速缓存转换为另一个模型预期的格式。如果解决了这个问题，跨模型KV缓存传输在两个方向上都有好处。从小型到大型的模型转换提升了输出的质量。例如，一个廉价的小模型可以处理代理工作流的常规部分，但要解决复杂的推理问题，你可以将KV缓存映射到一个更大的模型，并无缝地继续这个过程。另一方面，从大到小的模型转换降低了计算成本。一个功能强大的大型模型可用于在会话开始时解压缩一个庞大而复杂的系统提示或合成一个密集的PDF。一旦繁重的工作完成，会话的KV缓存就会被映射到一个更小、更经济的模型，以处理随后的快速对话。之前已经有人尝试解决KV缓存传输问题，但它们受到一些关键限制。这些包括需要昂贵的基于梯度的训练或非常严格的架构约束。在这项初步研究中，作者将研究重点限制在家庭内部转移，例如在Qwen、Llama或Ministral家庭中不同大小的模型之间进行转换。这些模型共享标记器、训练数据DNA和核心架构风格，但大小和深度不同。然而，这个框架为未来的实验留下了很大的空间。研究人员指出，这项技术最终可能会扩展到跨家族转移、不匹配的KV人数或将标准注意力与其他记忆机制相结合的混合架构。英伟达研究的关键发现是，交叉模型KV缓存是一种显著的线性结构。这意味着您可以使用简单的代数技巧进行映射，而不需要进行繁重的神经网络训练。例如，在实验从140亿参数的Qwen3模型到320亿参数版本的KV缓存传输时，作者发现，从一个源层到目标层的简单线性回归映射可以恢复目标密钥中56%的方差和目标值中32%的方差。当组合多个源层时，这些数字分别攀升至79%和65%。为了将这种线性关系转化为一个实用的系统，研究人员设计了一个具有三个关键组成部分的闭式人头脊映射器：人头脊回归：他们使用几百个文本序列的微小校准集来拟合简单的线性回归，而不是使用复杂的深度学习来训练系统。这项技术为每个注意力头独立解决了经典的最佳拟合问题。跨层源选择：由于源模型和目标模型的层数不同，映射器会评估并选择最具预测性的源层，以馈入每个特定的目标层。这样，系统只会从旧模型中选取最有用的内存片段来构建新模型的内存。内容空间映射：在转换数据之前，映射器会剥离RoPE编码。RoPE或旋转位置嵌入是一种标准机制，它对数据应用数学上的、与位置相关的旋转，以便模型理解序列中标记的顺序。剥离RoPE值可以使映射器泛化到长度大于其训练数据的序列。
