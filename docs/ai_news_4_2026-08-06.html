Meta launches Muse Code, an AI agent for large code bases
Meta, considered a bit of a straggler in the AI harnesses realm, is making strides to catch up. This week, the company released a new terminal coding agent aimed at programmers looking for assistance with complex tasks across large software code bases. Muse Code, which is currently available in beta, can accomplish “complete software engineering tasks across large repos,” Meta CEO Mark Zuckerberg said in a social media post on Wednesday. Those tasks include “planning changes, writing code, validating the results,” he added. Code, which can be installed with a single command, is powered by Meta’s previously released coding model, Muse Spark. It handles large projects by launching its own agents, which then work simultaneously. “When a job is big enough, it fans out to separate sub-agents working in parallel in isolated worktrees,” Zuckerberg explained. “Your working copy is never touched. In testing we had it build six features for a game simultaneously with no collisions.” The move attempts to position Meta more competitively, and more affordably, with AI lab peers like OpenAI and its coding agent Codex, and Anthropic with Claude Code. “We think that for a lot of workflows and a lot of use cases, this can be an incredibly good option, especially from a cost perspective,” Alexandr Wang, Meta’s AI chief who leads Meta Superintelligence Labs, told the Wall Street Journal. Meta has been attempting to grow its AI presence by pouring money into development. In June, it expanded beyond its core focus of using AI to support its advertising business and entered the enterprise AI market with an agent aimed at customer service and support.

Meta推出Muse Code，一个用于大型代码库的AI代理
Meta被认为是人工智能领域的一个落后者，正在大步追赶。本周，该公司发布了一种新的终端编码代理，旨在帮助程序员处理大型软件代码库中的复杂任务。Meta首席执行官马克·扎克伯格周三在社交媒体上发帖称，Muse Code目前处于测试阶段，可以完成“跨大型仓库的完整软件工程任务”。他补充道，这些任务包括“规划更改、编写代码、验证结果”。代码可以通过一个命令安装，由Meta之前发布的编码模型Muse Spark提供支持。它通过启动自己的代理来处理大型项目，然后这些代理同时工作。扎克伯格解释说：“当一项工作足够大时，它会分散开来，在孤立的工作树中并行工作的子代理。”。“你的工作副本从未被触碰过。在测试中，我们让它同时为游戏构建六个功能，没有冲突。”此举试图让Meta与OpenAI及其编码代理Codex等人工智能实验室同行以及与Claude Code合作的Anthropic更具竞争力，也更经济实惠。Meta的人工智能主管、Meta超级智能实验室的负责人Alexandr Wang告诉《华尔街日报》：“我们认为，对于很多工作流程和很多用例来说，这可能是一个非常好的选择，特别是从成本的角度来看。”。Meta一直试图通过向开发投入资金来扩大其人工智能业务。6月，它超越了使用人工智能支持其广告业务的核心重点，并与一家旨在提供客户服务和支持的代理商一起进入了企业人工智能市场。
